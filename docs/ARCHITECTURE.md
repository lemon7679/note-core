# InkEngine 설계

## 전체 흐름

```
 UITouch (240 Hz, coalesced / predicted / estimated)
        │  InputPoint
        ▼
 ┌────────────── StrokeBuilder ──────────────┐
 │ 1€ 필터 → (손떨림 보정) → 중복 병합          │
 │ → 속도 EMA → 필압(EMA+곡선 / 시뮬레이션)     │
 │ → 기울기 → 굵기·불투명도·시작 테이퍼          │   펜을 떼면: 따라잡기, 갈고리 제거,
 │ → StrokePoint (다이내믹스가 구워진 제어점)    │   끝 테이퍼, (멈춤 시) 도형 스냅
 └───────────────────────────────────────────┘
        │ points (+ predicted)
        ▼
 Tessellator: Centripetal Catmull–Rom 샘플링 → 프리미티브
   CapsulePrim (둥근 팁) / NibPrim (평닙) / StampPrim (연필)
        │
        ├─► GPU (Metal): 인스턴스 쿼드 + SDF 프래그먼트 → MAX 커버리지 → 합성
        └─► CPU Rasterizer: 같은 수식 (내보내기, 썸네일, 테스트 기준)

 PageEditor = Page(Layers of immutable Strokes) + History(ChangeSet) + dirty rect
```

## 핵심 설계 결정

### 1. 다이내믹스를 제어점에 "굽는다"
`StrokePoint`에는 필압 곡선·속도·테이퍼·기울기가 모두 반영된 최종 굵기/불투명도가 저장됩니다.
렌더링은 획 데이터만의 순수 함수이므로

- 지우개로 잘라도 조각이 원래 모양을 그대로 유지하고 (테이퍼가 새로 생기지 않음),
- 브러시 프리셋을 나중에 바꿔도 기존 노트가 변하지 않으며,
- 어느 플랫폼에서 열어도 같은 결과가 나옵니다.

### 2. 1€ 필터 + 뷰 공간 기준
고정 이동평균은 떨림을 줄이는 만큼 지연(고무줄 느낌)을 만듭니다. 1€ 필터는 속도에 따라 차단
주파수를 올려 느릴 때만 강하게 다듬습니다. 필터·속도·최소 거리·갈고리 길이는 모두 **뷰 포인트**
기준(`setViewScale`)이라 확대 상태에서도 손에 느껴지는 감각이 같습니다
(테스트 `builder_feel_is_zoom_invariant`).

### 3. Centripetal Catmull–Rom
균일 매개변수 Catmull–Rom은 점 간격이 불균일할 때(빠른 획) 고리·첨점이 생깁니다.
centripetal(α=0.5)은 이것이 수학적으로 일어나지 않으며, 제어점을 정확히 통과합니다.
도형 스냅의 꼭짓점은 `kPointSharp`로 표시해 둥글게 깎이지 않게 합니다.

### 4. SDF 프리미티브 + 획 단위 MAX 합성
- 둥근 팁은 반지름이 다른 두 원을 잇는 **uneven capsule**의 정확한 거리 함수로 그립니다.
  인접 캡슐이 끝 원을 공유하므로 이음매가 없고, 픽셀 단위 커버리지 `clamp(0.5 - d)`로
  어떤 배율에서도 깨끗한 안티앨리어싱이 됩니다. 0.5 px보다 가는 선은 굵기를 0.5 px로 두고
  알파를 줄여 끊기지 않고 옅어지게 합니다.
- 평닙(형광펜 치즐, 캘리그라피)은 닙 선분을 두 위치 사이로 쓸어낸 사다리꼴 + 모서리 반경입니다.
- 한 획의 프리미티브는 먼저 커버리지 마스크에 **MAX**로 누적한 뒤 한 번만 색/불투명도/블렌드로
  합성합니다. 그래서 반투명 펜이 자기 자신과 겹쳐도 얼룩(구슬 모양)이 생기지 않고,
  별개의 획끼리만 진해집니다 — 실제 형광펜과 같은 동작입니다.

**래스터화 비용 (0.2.0)** — 모든 프리미티브는 볼록하므로 픽셀 행마다 한 구간만 덮습니다. 행마다
두 구간을 해석적으로 구합니다.

| 구간 | 계산 | 처리 |
|---|---|---|
| 바깥 (도형 ⊕ 0.5 px) | 볼록 다각형의 띠 [y−R, y+R] 안 x 범위 + R | 이 밖은 건너뜀 |
| 안쪽 (도형 ⊖ 0.5 px) | 원판의 수평 현 몇 개를 다각형에 쓸어 붙인 구간의 볼록 껍질 | SDF 없이 바로 채움 |

SDF는 두 구간 사이의 안티앨리어싱 띠에서만 계산하고, MAX 누적이므로 이미 최대값인 픽셀은 바로 넘깁니다.
비용이 `면적 + 둘레`에 비례합니다. 예전에는 프리미티브마다 경계 상자 전체에서 SDF를 계산했는데,
형광펜 닙의 경계 상자는 폭의 2배 정사각형이라 확대 5배(폭 300 px)에서 픽셀당 수백 번 중복 계산했습니다.

또한 벡터 획은 곡선 샘플 간격(`maxChordPixels`, 화면 4 px)을 직선 구간에서 잉크 폭의 절반까지
늘립니다(`TessellationOptions::widthChordFactor`). 캡슐·닙 스윕은 직선 이동에 대해 정확하므로 결과는 같고,
곡선은 각도 제한(6°)이 그대로 정밀도를 보장합니다. 구간(세그먼트)마다 정해지므로 증분 테셀레이션도 그대로 정확합니다.

타일 렌더러(`*_render_over_rgba`)는 premultiplied RGBA8 픽셀에 바로 합성합니다(`Rasterizer::renderGeometryOver`).
타일 전체를 float로 바꿨다 되돌리지 않고, 각 획이 덮는 픽셀만 건드립니다. 프리미티브는 페이지 공간에서
먼저 타일과의 교차를 검사한 뒤 필요한 것만 픽셀 공간으로 변환합니다.

### 5. 연필: 페이지 고정 종이 결 + 흑연 밀도 누적
결 텍스처는 획이 아니라 **페이지 좌표**에 고정됩니다. 그래서 여러 획을 겹쳐 칠해도 같은 종이
돌기가 드러나고, 그리는 중에 무늬가 흘러다니지 않습니다. 텍스처는 크기가 다른 **둥근 가우시안 돌기**를
흩뿌려 만듭니다(고운 돌기 + 약한 덩어리 + 아주 옅은 얼룩 + 가로 섬유). 격자 노이즈의 네모 무늬나
텍셀 단위 백색 잡음(자글자글한 소금-후추 점)이 없고, 히스토그램 평활화로 임계값 t가 정확히 (1−t) 비율의
돌기에 흑연을 묻힙니다. 필압이 낮으면 돌기 꼭대기 위주로, 높으면 골까지 채우되 전환 폭이 넓고 골에도
막(floor)이 남아 부드러운 얼룩 정도로만 드러납니다.

스탬프는 MAX가 아니라 **흑연 밀도로 누적**합니다. 스탬프마다 `λ·w(거리)·침착(결, 깊이)`를 더하고
획의 커버리지는 `1 − exp(−밀도)`(Beer–Lambert)입니다. 스탬프 간격은 폭에 대한 고정 비율이므로 한 점을
덮는 스탬프 수 n을 알 수 있고, λ = −ln(1−α)/n 으로 정하면 직선 획의 중심이 정확히 스탬프 알파 α가 됩니다.
그 결과
- 가장자리 단면이 원판 낙하(falloff)의 적분이라 둥글고 부드럽습니다(몽글몽글한 느낌).
- 고리·되돌아 긋기처럼 같은 획이 다시 지나간 곳은 실제 흑연처럼 진해집니다.
- 스탬프별 불투명도 흔들림이 평균되어 얼룩 대신 고른 톤이 됩니다.

눕힌 펜은 타원 스탬프 + 약간 얕은 침투로 넓고 옅은 음영을 만듭니다. Metal 참조 셰이더도 같은 모델입니다
(스탬프는 더하기 블렌딩으로 밀도 텍스처에, 합성 단계에서 1 − exp(−밀도)).

### 6. 증분 실시간 렌더링
`StrokeBuilder::updateGeometry`는 다음을 돌려줍니다.
- `stable`: 더 이상 바뀌지 않는 프리미티브(단조 증가). 렌더러는 새로 추가된 부분만
  실시간 획 커버리지 텍스처에 한 번 구워 넣습니다.
- `tail`: 마지막 몇 구간 + 예측점. 매 프레임 다시 그립니다.

점이 "안정"이 되는 조건: 스플라인 지지점 4개가 모두 확정되고, 필압 추정치 갱신을 기다리는
점이 아닐 것(최대 250 ms). 그래서 프레임 비용은 획 길이와 무관합니다
(테스트 `builder_live_stable_geometry_is_prefix_of_final`).

### 7. 가역적인 편집 (ChangeSet)
모든 편집은 `{제거된 획(이전 인덱스), 추가된 획(이후 인덱스)}` 하나의 형태로 표현됩니다.
추가·삭제·정밀 지우개(1획 → N조각, z-순서 유지)·변형·색 변경이 모두 같은 코드로
적용/되돌리기 됩니다. 획은 불변(`shared_ptr<const Stroke>`)이라 실행 취소 기록과 렌더 스레드가
잉크를 복사하지 않습니다.

- **지우개 제스처 = 순변화 하나**: 드래그 동안의 변경은 그룹으로 모았다가, 끝날 때 시작 시점과 끝 시점의
  획 목록을 비교한 순변화(원래 획 → 최종 조각) 하나로 바꿔 기록합니다(`History::endGroup(page)`).
  긴 획을 수백 번 자르는 동안 생겼다 사라진 중간 조각은 메모리에 남지 않습니다.
- **다시 그릴 영역(damage)**: 벡터 획을 정밀 지우개로 자르면 조각은 자른 곳에서 스플라인 지지점 몇 개
  떨어진 곳부터 원래 획과 같은 프리미티브를 만듭니다. 그래서 `ChangeSet::damage`에는 자른 부근
  (영향받은 제어점 + 잉크 폭)만 넣고, `takeDirty()`가 이를 돌려줍니다. 연필(스탬프 배치가 조각마다 다시 시작)과
  서로 겹치는 조각(한 획일 때는 MAX, 조각끼리는 누적)은 획 전체 영역을 씁니다. 부분 재렌더 결과가 전체 재렌더와
  같은지 `c_api_erase_damage_repaint_matches_full_render` 테스트가 확인합니다.

### 8. 그리고 멈추기 도형 (`shape_recognizer.cpp`)
1. 경로를 호 길이 기준 96점으로 재표본화합니다(입력 속도와 무관한 판정).
2. 판정 순서: 직선 → (닫힌 경로) 다각형 3–6각 → 타원/원 → (열린 경로) 호 → 꺾은선.
   - 다각형: RDP 단순화 후 각 꼭짓점을 "이웃 꼭짓점을 잇는 선에서 가장 먼 점"으로 다시 맞춰
     둥글게 그려진 모서리도 정확히 잡습니다. 각 변이 실제로 곧은지(변 길이 대비 평균 편차)를
     검사하므로 원이 육각형으로 오인되지 않습니다.
   - 호: 최소제곱 원 맞춤(Kåsa), 각도가 한 방향으로 25°–330° 진행할 때만 인정합니다.
3. 자동 정형화(`regularizeShape`)는 허용 오차 안에서만 적용됩니다. 정사각형 10%,
   정삼각형 12%, 정다각형 16%, 직각 ±10°이고, 반원·직각호는 ±10°에서 맞춥니다.
4. 스냅 후 드래그(`dragTransform`): 고정점(직선·호·꺾은선은 시작점, 닫힌 도형은 중심)을 기준으로,
   스냅 순간의 펜 위치가 현재 펜 위치로 가도록 하는 닮음변환입니다. 회전에는 6°의 부드러운
   여유 구간이 있어 크기만 바꿀 때 기울지 않습니다.

### 9. 글씨 보정 (`correction.cpp`)
**획 다듬기**는 점의 개수와 굵기·필압 등 속성은 그대로 두고 위치만 바꿉니다.
1. 모서리 검출: 각 점에서 ±w(≈2.5 뷰 pt) 구간의 방향 변화가 45° 이상이고, 절반 구간에서도
   그 65% 이상 꺾일 때(집중된 꺾임)만 모서리로 봅니다. 그래서 ㅇ·고리 같은 곡선은 잘리지 않습니다.
2. 모서리 사이 구간을 분류합니다. 길이 대비 최대 편차가 2.5–7%(강도에 비례) 이내면 직선,
   축과 4–12° 이내면 수평·수직입니다.
3. 수평 구간으로 이어진 모서리들은 같은 y, 수직 구간으로 이어진 모서리들은 같은 x를 갖도록
   union-find로 묶어 평균값으로 맞춥니다. ㄱ·ㄹ·ㅁ의 모서리가 떨어지지 않고 정확한 직각이 됩니다.
4. 직선 구간은 원래 간격(=쓰는 속도)을 유지한 채 선분 위로 옮깁니다. 곡선 구간은 호 길이 가중
   가우시안의 twicing(2·G − G∘G)으로 떨림을 지웁니다. 일반 가우시안은 곡선을 안쪽으로 줄이지만
   twicing은 수축을 2차까지 상쇄합니다. 양 끝(모서리)은 고정합니다.
5. 빌더에서는 갈고리 제거 다음, 테이퍼 계산 전에 실행됩니다. 펜을 떼는 순간 획이 정리됩니다.

**줄 정렬** (`straightenHandwriting`):
1. 투영 프로파일 기울기 보정: ±30° 범위에서 잉크를 수직축에 투영한 히스토그램의 제곱합이
   최대가 되는 각도를 찾습니다(1° → 0.1° 2단계 탐색). 개선이 2% 미만이면 회전하지 않습니다.
2. 줄 나누기: 가로로 가깝고(2.5T 이내) 세로 중심이 비슷한(0.75T + 기울기 여유) 획을 연결해
   줄을 만듭니다. 연결이 국소적이어서 아직 기울었거나 물결진 줄도 하나로 묶입니다.
   점·짧은 획은 가장 가까운 획의 줄에 붙습니다.
3. 줄마다: 단어(가로 간격 0.8 줄높이 이상에서 분리)의 잉크 중심으로 가중 최소제곱 직선을 맞춰
   남은 기울기를 없앤 뒤, 단어를 줄의 중앙선(가중 중앙값)에 맞춥니다.
4. 각 획에는 강체 변환(회전 + 이동)만 적용하므로 글자 모양은 변하지 않습니다. 강도 k는 회전각과
   이동량을 k배로 보간합니다.

## 튜닝 포인트

펜별 손맛은 `engine/src/brush.cpp`의 프리셋에 모여 있습니다.

| 파라미터 | 의미 |
|---|---|
| `dynamics.width` | 기준 굵기(pt). `mmToPt(0.5f)` = 0.5 mm |
| `pressureCurve` | 필압 반응 곡선 (베지어 제어점 2개) |
| `pressureWidthMin/Max` | 필압 0/1일 때 굵기 배율 |
| `pressureOpacityMin/Max` | 필압 0/1일 때 불투명도 (연필) |
| `velocityThinning`, `velocityReference` | 빠를수록 가늘어지는 정도 / 기준 속도(뷰 pt/s) |
| `taper.startLength/endLength` | 테이퍼 길이(굵기의 배수), `velocityScaledEnd`로 들어올리는 속도 반영 |
| `tilt.*` | 연필 눕힘 음영 시작/최대 각도, 굵기·불투명도 배율 |
| `smoothing.pencil/touch` | 1€ 필터 (minCutoff, beta) — 스타일러스/손가락 별도 |
| `smoothing.stabilizer` | 손떨림 보정 (당김줄 길이 또는 이동평균 창) |
| `hookLength` | 갈고리로 간주할 최대 길이(뷰 pt) |
| `snapOnHold`, `holdDuration`, `holdTolerance` | 그리고 멈추기 도형 (멈춤 시간, 허용 흔들림) |
| `correction.strength` 외 | 글씨 보정 강도·항목(실시간 보정 / 곡선 다듬기 / 직선화 / 수평·수직 맞춤) |
| `ShapeRecognizerOptions` | 도형 판정 허용 오차, 정형화 허용 오차 |
| `style.hardness/spacing/grainStrength/grainScale` | 연필 스탬프 경도·간격·결 강도·결 크기 |
| `style.nibAngle/nibThickness` | 평닙 각도·두께 |

실기기에서 조정할 때는 `ink_demo`의 합성 입력 대신 실제 녹화한 터치 시퀀스를 넣어 비교하는 것을
권장합니다 (InputPoint 배열을 저장/재생하면 됩니다).

## 스레드 모델

에디터(`PageEditor` / `InkEditor`)와 빌더는 스레드 안전하지 않습니다. 권장 구성:
- 메인 스레드: 입력 → `StrokeBuilder`, 편집 → `PageEditor`
- 렌더·저장 스레드: **스냅숏**(`ink_editor_snapshot`)을 받아 사용합니다. 스냅숏은 페이지의 불변 사본
  (획은 `StrokePtr` 공유, 레이어 목록만 복사)이라 만드는 비용이 포인터 복사뿐이고, 편집이 없으면 같은 사본을
  공유합니다. 여러 작업 스레드가 동시에 `ink_snapshot_render_over_rgba` / `ink_snapshot_save`를 호출해도
  되고, 그동안 메인 스레드는 계속 편집할 수 있습니다.
- 테셀레이션 캐시는 에디터와 스냅숏이 공유하며 뮤텍스로 보호됩니다. 테셀레이션 자체는 잠금 밖에서 하고,
  획마다 확대 단계 2개(화면 타일 + 미리보기)를 보관합니다. ThreadSanitizer로 동시 렌더 테스트를 확인했습니다.
- 래스터라이저의 작업 버퍼는 `thread_local`입니다.
